# Security reporting

Report suspected vulnerabilities privately to
[cameron@agent-events.dev](mailto:cameron@agent-events.dev), maintained by
[@link108](https://github.com/link108). Do not include vulnerability details,
credentials or private payloads in public issues.

If GitHub private vulnerability reporting is enabled, you may also use the
repository's **Security → Report a vulnerability** action:
[private report](https://github.com/agentevents-org/spec/security/advisories/new).
The email address above is the private reporting contact regardless of that
feature's availability.

This specification defines event contracts; deployed producers and consumers
are responsible for content capture, schema resolution, retention and access
controls. See the [sensitive-content policy](spec.md#sensitive-content) and
[schema resolution policy](spec.md#schemauri).
